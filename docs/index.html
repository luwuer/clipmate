常见问题。

安装与首次使用

macOS 首次打开提示「无法验证开发者」？
CI 构建的 DMG 未做 Developer ID 签名公证。首次打开：右键 Clipmate.app → 打开 → 再点「打开」；或到 系统设置 → 隐私与安全性 页面底部点「仍要打开」。之后正常双击即可。
macOS 粘贴需要授权？
是。粘贴到其他应用需要「辅助功能」权限，Clipmate 启动时会自动请求。若设置列表里找不到，用菜单栏「申请辅助权限并打开设置」入口，或 系统设置 → 隐私与安全性 → 辅助功能 → 手动添加。Windows 无此概念，装好即用。
Windows 安装时 SmartScreen 警告？
安装包未购买代码签名证书。点「更多信息 → 仍要运行」即可；介意的话可自行从源码构建。
数据存在哪里？会上传吗？
纯本地，无任何网络行为。macOS 在 ~/Library/Application Support/com.mdy.clipmate/，Windows 在 %APPDATA%\com.mdy.clipmate\；文本历史存 history.jsonl（图片仅内存）。
